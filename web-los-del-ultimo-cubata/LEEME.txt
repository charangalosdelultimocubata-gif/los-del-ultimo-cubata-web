LOS DEL ÚLTIMO CUBATA — WEB PROFESIONAL

CONTENIDO
- index.html: web responsive, con secciones Nosotros, Eventos, Galería, Contacto y Patrocinadores.
- assets/: logotipo, carteles y logotipos separados de patrocinadores.

PROBAR
1. Descomprime el archivo ZIP.
2. Abre index.html en Chrome, Edge, Firefox o Safari.
3. No muevas index.html fuera de la carpeta; debe permanecer junto a assets.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea un repositorio público en GitHub.
2. Sube index.html y la carpeta assets completa.
3. Abre Settings > Pages.
4. Selecciona Deploy from a branch, rama main, carpeta /(root), y guarda.
5. Espera a que GitHub genere la URL pública.
